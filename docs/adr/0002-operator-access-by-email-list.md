# Operators see all Workspaces via an email list, not membership

OpenReply has no cross-workspace role: a user always lands in the first Workspace they belong to, and admin rights exist only per Workspace. We need appscale staff to oversee every influencer's Workspace while influencers stay isolated from each other. Instead of inviting staff as ADMIN into each Workspace (manual step per influencer, no switcher), users whose email is listed in `OPERATOR_EMAILS` get a Workspace switcher over all Workspaces and ADMIN rights everywhere, without membership rows. Influencers keep the default flow: first login auto-creates their Workspace as OWNER.
